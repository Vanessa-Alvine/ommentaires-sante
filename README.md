# Générateur de commentaires — Santé (Le Cocon Santé)

Générateur de commentaires de bulletin en santé (BPS, étape 1, étape 2), 1re à 6e année, selon le guide AEFO.

Application autonome : tout est contenu dans `index.html`. Aucune installation.

Les données (élèves, commentaires) sont enregistrées **uniquement dans le navigateur** de l'utilisateur (localStorage). Rien n'est envoyé sur un serveur.
